## 🚀 Getting Started on Windows

1. Visit this link to download the application: [https://github.com/ithony77/Forma](https://github.com/ithony77/Forma).
2. Make sure Node.js 18.17 or newer is installed. Any later version works except the short-lived 19.x and 20.0–20.2 releases. If you start Forma on a release older than the security updates it was reviewed with, such as 24.21.0 in 24.x or 22.23.3 in 22.x, Forma prints a one-line notice but still starts.
3. Extract the entire ZIP to a normal folder. Do not run it inside the ZIP viewer.
4. Double-click `start.cmd`.
5. Keep the terminal window open. Forma needs that window to stay running.
6. The app opens in your browser. Use the browser window to begin building.

## 🛠️ How Forma Works

1. Describe the website or frontend you want.
2. Forma’s JEV-classifier selects design settings, component variants, typed fields, panels, internal UI elements, and section order.
3. Review the generated layout in the editor.
4. Change text, sections, components, fields, and panel settings.
5. Save the project so you can return to it later.
6. Export standalone HTML when you are ready to use the result outside Forma.

## 🧩 Editing the Result

The editor gives you visual control over the page. You can adjust the content and structure without programming. Depending on the project, you may work with headers, text blocks, buttons, forms, cards, lists, panels, and other interface parts.

Use the editor panels to change component variants, typed fields, and internal UI elements. Reorder sections when you want a different flow. The goal is to let you move from a description to an editable website or application interface quickly.

## 📦 Saving Projects and Exporting HTML

Save your project inside Forma so you can continue editing later. When the result is ready, export standalone HTML. The exported HTML can be opened in a browser and used as a starting point for publishing or sharing your page.

Forma is local-first, so your project work is centered on your computer. Save projects regularly and export a copy when you reach a version you want to keep.

## 🔐 Local-First Workflow

Forma is built around a local-first workflow. You run the app on your computer, keep the terminal window open while it runs, and manage project files in your local folders. This makes Forma suitable for users who want to build and edit website interfaces on their own machine.

## 🆘 Troubleshooting

If `start.cmd` does not open Forma, confirm that Node.js 18.17 or newer is installed and that the ZIP was fully extracted to a normal folder.

If the terminal window closes, open `start.cmd` again and keep the new terminal window open while you use Forma.

If the browser does not open automatically, look at the terminal window for the local address and open it in your browser.

If you see a one-line notice about an older Node.js release, Forma can still start. You can continue working, or update Node.js later.

If the download page does not show the package, revisit [the Forma download page](https://github.com/ithony77/Forma) and use the download option there.

## 💡 Tips for New Users

- Describe the page in clear, simple language.
- Start with one page or one interface before building a larger project.
- Save the project before making big changes.
- Use short section names so the layout is easy to scan.
- Export HTML when you reach a version you want to keep.
- Keep the terminal window open the whole time Forma is running.
